# Hachi branding assets

- [Continuous wag preview](hachi-menu-wag.gif): exported from the current AppKit menu-bar renderer, looping every 0.9 s.
- [Monochrome menu-bar artwork](hachi-menu-icon.png): resting side profile, transparent PNG.
- [Color application artwork](../hachi.png): the static app badge.

`hachiIcon` and `wagPose` in [`main.swift`](../../main.swift) are the editable source. macOS Reduce Motion disables the live animation. The GIF is a preview, not an operational status indicator.
