# Hachi 威胁模型

Hachi 的范围：**提醒用户当前的网络出口位置，并在已批准的路径失效时安全断网。** 它不改变任何平台账号的资格，也不帮人绕开地区限制或平台执行。常见问题见 [范围 FAQ](scope-faq.md)。

本文只写 Hachi 想防什么、不防什么，以及每一项现在有没有验收证据。证据状态来自 [`release-gate.json`](../release-gate.json) 和 [`evidence/`](../evidence/README.md)：没有证据文件就写“未验证”，不写任何没有证据的承诺。

## 当前状态（先看这里）

Hachi 现在是开发原型。它只观察 macOS 的网络路径是否可用，并可按需调用本机已安装的预检适配器；**它还没有运行时的流量执行或阻断能力**，也不覆盖浏览器授权和 MCP。网络可用不等于已验证出口 IP。`evidence/` 目前没有任何门槛的证据文件，下表因此全部是“未验证”。

## Hachi 想防什么

| 威胁 | 说明 | 对应门槛 | 证据状态 |
| --- | --- | --- | --- |
| 隧道掉线 | 批准的隧道或代理核心中断后，受保护流量不应改走直连 | G3 `inject_tunnel_core_loss`；G2 | 未验证 |
| 错路出口 | 路由变化、网卡切换、睡眠唤醒后，流量不应从未批准的路径出去 | G3 `inject_route_change`、`inject_interface_switch`、`inject_sleep_wake`；G2 | 未验证 |
| 已打开的连接 | 路径失效时，已经建立的连接不应继续走旧路径 | G3 `inject_already_open_flows`；G2 | 未验证 |
| DNS 旁路 | IPv4 / IPv6 的 DNS 查询不应离开批准路径 | G3 `dns_ipv4`、`dns_ipv6`；G2 | 未验证 |
| UDP 旁路 | UDP 流量不应离开批准路径 | G3 `dns_udp`；G2 | 未验证 |
| 浏览器授权和回环回调 | 系统或浏览器重定向、本机回调不应走到未批准的路径 | G3 `system_redirect`、`browser_redirect`、`loopback_callback` | 未验证 |
| 长连接与令牌刷新 | TCP/TLS 重连、类令牌刷新期间保持同一路径 | G3 `tcp_tls_reconnect`、`token_like_refresh` | 未验证 |
| 子进程与 MCP | MCP 的 stdio 子进程隔离和远程流式传输（仅在声明支持 MCP 时适用） | G3 `mcp_stdio_child_isolation`、`mcp_remote_streaming` | 未验证 |
| 扩展不可用或更新 | 网络扩展被禁用、重启或更新时的行为 | G3 `inject_update`、`inject_extension_disable_restart`；G5 | 未验证 |
| 无关流量被误伤 | 对照工作负载不应被中断或改路 | G2 | 未验证 |
| 端到端可靠性 | 每个声明的工作流成功率达到门槛 | G1 | 未验证 |
| 真实客户端上的表现 | 夹具上的结果能否迁移到真实签名客户端 | G4 | 未验证 |
| 菜单和提醒的呈现 | 每个状态有截图，维护者在真机走查并签字 | G6 | 截图由 CI 渲染；维护者签字未验证 |

“对应门槛”只表示这项要靠哪个门槛来验证，不表示已经通过。G2 要求在独立于 Hachi 进程的网络观察器上看到结果，应用日志不算证据。

## Hachi 不防什么

- **账号是否受影响。** Hachi 不改变、也不预测任何平台账号的状态。
- **是否符合服务条款。** 是否符合某个服务的条款和所在地的规定，由使用者自己判断；Hachi 不替人判断，也不提供这方面的保证。
- **受损系统。** 如果设备已被入侵、系统被篡改或有恶意软件，Hachi 的提醒和断网都不可靠。
- **用户主动关闭保护。** 用户退出 Hachi、停用扩展或修改系统网络设置后，保护不再有效。
- **出口之外的信息。** 应用层的指纹、账号行为、支付信息等不在 Hachi 的范围内。
- **上游服务本身。** 隧道或代理服务端的可信度、日志和可用性不在 Hachi 的范围内。

## 读这份文档的方式

“想防”不等于“已防住”。只有当 `evidence/` 下有对应证据，并且 `tests/acceptance.py` 的门槛评估通过，对应一行才可以改成已验证；改证据只能由维护者完成。证据的格式和限制见 [`evidence/README.md`](../evidence/README.md)。
