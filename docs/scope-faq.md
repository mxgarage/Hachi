# 范围 FAQ

Hachi 做的事很窄：**告诉你现在的网络出口在哪里，并在已批准的路径失效时断网。** 下面是常被问到的问题，答案很直接。更细的防护范围和验证状态见 [威胁模型](threat-model.md)。

**Hachi 能不能帮我换出口？**
不能。Hachi 只报告当前出口位置，不提供、不推荐、不切换出口。

**Hachi 能不能帮我绕开地区限制？**
不能，也不会做。这类需求不在范围内，相关 issue 会直接关闭。

**Hachi 会不会保证我的账号不被封？**
不会。Hachi 不改变平台账号的资格，也不对任何账号结果做承诺。

**用了 Hachi 是不是就符合某个服务的条款？**
不是。是否符合条款由你自己判断，Hachi 不提供这方面的保证。

**Hachi 能不能让某个应用看起来来自别的地区？**
不能。Hachi 不伪装任何位置信息。

**Hachi 能保证不泄漏流量吗？**
现在不能这样说。当前版本只观察网络路径，还没有运行时的流量执行能力，各项防护的验收证据见 [威胁模型](threat-model.md)，没有证据的一律是“未验证”。

**你们有受限地区的使用教程吗？**
没有，也不会写。

**Hachi 会收集我的数据吗？**
当前原型没有遥测，不自动使用凭据，也不引入第三方依赖。详见 [README](../README.md)。

**我的需求不在范围内，怎么办？**
欢迎提 issue 时先看一下 [issue 模板](../.github/ISSUE_TEMPLATE/)。超出范围的请求会被标上“超出范围”标签并直接关闭。
