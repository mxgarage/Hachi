# Hachi v0.2-dev.2（开发预发布，仅供体验试用）

> **这不是正式版。** 发布门槛还没有满足（上一版 v0.2-dev.1 的验收报告里满足 0 项；本版的数字以发布页附带的验收报告为准）。本版只用来让你在自己的 Mac 上走一遍菜单和提醒，看看体验对不对。不要用它判断“网络是否安全”。

Hachi 只提醒你当前的网络出口位置，不改变平台账号资格，也不帮人绕开地区限制。它也不拦截任何流量，不覆盖浏览器授权和 MCP。

## 安装

1. 下载 `Hachi-v0.2-dev.2-macos.zip`，解压得到 `Hachi.app`。
2. 这个包是 ad-hoc 签名，**没有经过 Apple 公证**。第一次打开请在 Finder 里**右键 → 打开**（或在“系统设置 → 隐私与安全性”里点“仍要打开”）。
3. 没有 Dock 图标，也没有窗口，只会在菜单栏出现一只小狗。
4. 可选校验：`shasum -a 256 Hachi-v0.2-dev.2-macos.zip`，与 `.sha256` 文件里的值比对。

## 相比 v0.2-dev.1 有什么变化

对你能看到的部分：

- **提醒文字更清楚**：预检未通过时，提醒里会说明“Hachi 只转述预检入口的输出，不判断原因”，并说明未通过不一定是 IP 的问题（例如 IP 与预期不同，或 `observed_route=NOT OBSERVED` 表示没有观察到预期路由）。“未启动客户端”现在明确写成“这只是预检”，不再像是失败原因。
- **检查中的菜单行**：自 dev.1 之后的修复：菜单不再自动重新启用正在检查的那一行，`tests/ux_screens.py` 里有对应的回归检查（`checkingRowStaysDisabled`）。是否真的变灰、悬停提示是否变成“Hachi · 预检中”，请在走查 UX-09 时确认。

对开发和验收（不影响日常使用）：

- 新增 UI 验收：CI 会渲染每个菜单、提醒状态的浅色/深色截图，并和基线逐像素对比；PR 和 main 上有差异会让 CI 失败，发布时只警告。
- 新增逐项的手工验收清单（`docs/ux-checklist.md`）和本次的走查指南（`docs/walkthrough.md`）。
- 新增“手机出口对照（扫码配对）”的交互设计稿（`docs/phone-exit-check.md`）：只是设计，**尚未实现**，本版没有这个功能。
- 新增模型分工和日报的编排文档、`tests/lab.py` 对被拒绝的 URL、空的预期值和超大响应的测试、若干文档修正。
- 仓库已改为公开。

## 已知情况

- 发布门槛没有满足：运行中拦截、安全断网、Network Extension 等还没有实现。预检通过 ≠ 当前流量安全。
- 预检入口（`~/.local/bin/claude-safe`、`codex-safe`）不在本仓库里；Hachi 只运行它们的 `--check-only` 并显示输出。没有安装时，提醒会说明无法运行。
- 本版没有用真实预检入口做过验收，请按 `docs/walkthrough.md` 用示例入口走一遍。
